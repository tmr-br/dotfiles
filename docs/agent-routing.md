# エージェントルーティング

複数のコーディングエージェントをどう使い分けるかの方針。

## マシンの振り分け

- Xcode / iOS が要る作業 → mimolette
- それ以外 → cambozola（既定）。常時稼働が要るもの、長時間のものも cambozola
- mimolette は本人の手元作業と Xcode 専用に空けておく

## モデルの使い分け

- 実装の第一選択は Codex
- 設計判断とコードレビューは、実装したモデルとは別のモデルから独立に取る（単一モデルの自己申告で通さない）
- 画面まわりの実装は、非 UI の実装とは得意なモデルが違うので分けて考える
- 軽量モデルに量産タスクを回す場合は、強いモデルでの検品を必ずセットにする

## 委任の型

1. 作業はリポジトリの完全な clone（または専用 worktree）の中で行う。一時領域で作業しない
2. 委任先には、目的、完了条件、禁止事項を明記したブリーフを渡す
3. 委任先は成果物と結果メモを残す。git の操作（コミット、プッシュ、PR 作成）は委任先にさせず、取りまとめ側が行う
4. 取りまとめ側が実測で検品してから報告する。「終わった」という申告だけで完了にしない
5. 長時間の委任は、プロセスの生存とログの伸びを定期的に見張る。終了の合図だけに頼らない

## 同時編集の禁止

- 複数のエージェントに同じファイルを同時に編集させない
- 並行作業は git worktree を分けて行う
